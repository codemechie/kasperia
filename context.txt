GOAL:
AI Agent that searches 10-50 e-commerce sites for best deals. No LLM training — pure RAG + tool calling.
Ollama (Qwen/Mistral) orchestrates via MCP tool server.

---

ARCHITECTURAL OVERVIEW (Abstract Interface / Agent-Driven Scraping)

The project underwent a major re-architecting. The old approach (direct-scraping Nike/Adidas with
ad-hoc sync functions) has been replaced with an abstract, agent-driven pipeline:

LAYERED DATA FLOW:
  User Prompt → Ollama (tool_choice="auto") → search_products(query, domain)
    → Layer 1: state.cache (instant return)
    → Layer 2: state.scraper_registry (async BaseScraper.scrape_products)
    → Layer 3: Queue agent build + fallback parser (JSON-LD / OG meta)
